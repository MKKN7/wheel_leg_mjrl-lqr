# XML 模块化技能

## 拆分原则

- 当 XML 代码超过 1000 行时，按功能或部件拆分为多个文件。
- 使用 MuJoCo 的 `<include file="..."/>` 引入子文件。
- 子文件命名规范：`<部件名>.xml`，例如 `leg_left.xml`。

## 层级管理

- 保持 `worldbody` → `body` 的物理树结构。
- 每个子文件只包含一个或多个完整 `body` 定义，避免跨文件交叉引用。
- 顶层 `body` 放在主文件中，子部件放入 include 文件。

## 副本同步

- 若存在副本文件（例如左右对称部件），修改任一处必须同步更新所有副本。
- 使用 `@replace` 时注意同时替换所有副本。

## 验证

- 每次拆分后，运行 `@bash` 加载 XML 并检查关节数量、自由度是否一致。
