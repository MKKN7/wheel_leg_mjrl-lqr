
# 域随机化技能

## 通用随机化范围建议

- 质量：名义值 ±10%~20%
- 摩擦系数：0.5~1.5（地面与足端）
- 关节阻尼：名义值 ±30%
- 执行器延迟：0~2 个控制周期
- 观测噪声：高斯噪声，标准差为传感器量程的 1%~5%。对于真机可能测不准的维度加噪声延迟或随机置零，让policy鲁棒
- 地面硬度/接触参数：`solimp`/`solref` 随机化 0.5~1.5 倍.在课程学习中其强度可以由低逐渐升高

## MuJoCo 原生实现

- 在环境 `reset` 中随机采样，直接修改 `model` 参数或 `data` 状态。
- 使用 `np.random.uniform` 生成批量随机参数，避免循环。

## Isaac Lab 实现

- 使用 `EventManager` 注册随机化事件，在 `reset` 时按环境概率触发。
- 随机化参数在 GPU 上批量生成，避免 CPU 同步。
- 示例：`EventManager` 中注册 `mass_randomizer`，配置范围与概率。

## MuJoCo Warp 实现

- 随机化参数在 GPU 上使用 Warp 生成（如 `wp.rand`），并在核函数内更新模型参数。
- 保证随机数种子可复现，使用 `wp.set_seed`。

## 观测对齐

- 仿真传感器输出与实机同单位、同坐标系、同频率。
- IMU 加入偏置和随机游走噪声。
- 动作延迟随机化后，网络输入当前观测和历史动作（或使用 LSTM/Transformer）。
- Isaac Lab 中通过 `ObsNoiseManager` 或自定义噪声实现。

## 网络与训练技巧

- 使用 LayerNorm 或 BatchNorm 稳定训练。
- 策略输出采用 Beta 分布或高斯分布，动作均值经 tanh 后映射到关节限位。
- 残差学习时，RL 输出幅度限制在基准的 ±30% 以内。
- 训练使用 PPO 或 SAC，高频连续控制优先 PPO。

## 奇异规避

- 检测所有可能的运动学奇异（如膝关节完全伸直、髋关节极限）。
- 在奖励中加入关节限位惩罚，在动作 clip 中避免奇异区。
- LQR 设计时选择远离奇异的工作点。
