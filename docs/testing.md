# 测试技能

## 单元测试

- 环境 `reset`/`step` 接口符合 Gymnasium 规范，Isaac Lab 环境亦需满足。
- 测试 episode 终止条件、reward 计算、观测维度一致性。
- 奖励函数各分项单独测试，确保数值范围符合预期。
- 工具函数（坐标变换、传感器解析、域随机化采样）必须有确定性测试用例。
- Warp 核函数需与 NumPy/CPU 参考实现对比，误差 < 1e-6。

## 集成测试

- 无渲染模式下运行完整训练循环（含若干 step），验证无内存泄漏、无 NaN/Inf。
- 切换不同随机种子，确保环境可复现（Isaac Lab 中设置全局种子）。
- 验证 LQR 与 RL 残差叠加后动作在安全范围内。
- 在多环境并行下运行随机动作测试，确认所有环境状态一致（无同步错误）。

## 回归测试

- 每次修改奖励函数、环境物理参数、控制器逻辑后，运行预设场景（直行、转弯、跳跃、跌倒恢复）。
- 记录关键指标（速度跟踪误差、能耗、成功率），与基线对比。
- Isaac Lab 回归测试需包含不同并行环境数下的性能。

## 性能测试

- MuJoCo 原生：单步仿真耗时 < 1ms（1kHz 控制）。
- Isaac Lab：在目标 GPU 上测试 FPS，要求至少 1000 FPS（含数据采集开销）。
- Warp 核函数：测量 kernel 执行时间和数据传输开销，确保不成为瓶颈。
- 检查循环内是否构造 MjModel/MjData、重新加载 XML、CPU-GPU 频繁同步等违规。

## 安全测试

- 模拟异常输入（传感器噪声极大、动作超限、关节限位触发），验证 estop 和 fallback 逻辑正确触发。
- 检查电机扭矩是否超出 80% 额定值。
- Isaac Lab 中测试 GPU 内存越界保护和 OOM 恢复。
- Warp 核函数测试越界索引和极端输入。
