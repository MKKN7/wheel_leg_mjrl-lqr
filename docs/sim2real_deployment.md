# Sim2Real 部署技能

## 部署前安全检查

- 实机电机额定扭矩 > 仿真最大扭矩 × 1.25。
- 仿真中模拟落地冲击，验证主动迎地策略能降低峰值扭矩。
- 实机具备独立急停逻辑（硬件开关或软件监控），不依赖 RL 策略内部判断。
- 检查电流是否可能过大导致炸机，限制电流变化率。

## 主动迎地策略

- 检测到即将落地（如足端距离 < 阈值且速度向下）时，前 50ms 主动减小力矩。
- 实现时使用状态机：飞行相 → 预备落地 → 触地瞬间卸力 → 支撑相。

## 迭代流程

1. 理想仿真训练至收敛。
2. 逐步增加域随机化，记录成功率。
3. 实机测试先低速，逐步放宽速度/跳跃高度。
4. 若实机震荡，优先检查观测延迟和执行器延迟是否与仿真匹配，再调整奖励权重。
