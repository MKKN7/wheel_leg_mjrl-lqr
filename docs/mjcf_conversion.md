# MJCF 转换技能

## 网格处理

- 将 SolidWorks 的 STL 文件转换为 MJCF 时，必须去除多余网格。
- 每个几何体的三角面数量不得超过 2000。
- 若面数超标，使用简化工具（如 MeshLab）简化，但保持外形误差小于 1mm。

## 物理拓扑

- 根据现实装配连接关系，严格按照层级和物理拓扑嵌套 `body`。
- 每个 `body` 的子层级全部写完，最后与父层级一起用 `</body>` 封闭，保证层级分明。
- 禁止出现悬空或重复嵌套。

## Equality 限位

- 使用最少的 `equality` 约束（如 `connect`）防止散架，避免过约束导致自由度减少。
- 优先使用关节自然限位，而非额外 `equality`。
- `range` 限位符方向不要写反：下限在前，上限在后。

## 其他

- 若 XML 单文件超过 1000 行，必须使用 `<include>` 模块化拆分。
- 修改 XML 后，必须同步更新所有副本文件。
- 转换完成后，运行 `@bash` 验证模型可加载且无自由度异常。
